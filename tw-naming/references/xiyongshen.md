# 喜用神簡述

> **重要免責**：喜用神的判定是傳統命理中**最爭議**的環節。同一個八字，不同派別、不同命理師可能給出截然不同的喜用神。
> 此檔案僅給出最常見的入門法則，**不適合用於商業命名服務**。嚴肅場合請建議使用者諮詢專業命理師。

## 八字組成

```
年柱 月柱 日柱 時柱
天干 天干 天干 天干
地支 地支 地支 地支
```

- **日干**：日柱的天干，代表本人
- **月令**：月柱的地支，決定季節 / 旺衰

## 三大常見判定法

### 1. 扶抑用神（最常用）

判斷日干旺衰：
- **強**：月令同類 + 多比劫/印 → 用「剋洩耗」之五行
- **弱**：月令異類 + 多財官食傷 → 用「生扶」之五行

例：日干為「甲木」生於「申月」（金旺剋木），木弱 → 喜用神為「水、木」（水生木、木助木）。

### 2. 調候用神

看月份冷暖燥溼：
- 冬月生（亥子丑）+ 火少 → 用「火」調暖
- 夏月生（巳午未）+ 水少 → 用「水」調潤
- 春月生（寅卯辰）+ 木盛 → 視情況用「金」剋之或「火」洩之
- 秋月生（申酉戌）+ 金盛 → 視情況用「火」剋之或「水」洩之

### 3. 通關用神

兩個五行嚴重相剋時，用第三個五行通關：
- 木剋土強 → 用「火」（木→火→土）
- 金剋木強 → 用「水」（金→水→木）

## 簡單啟發式（給 LLM 用）

如果使用者沒有專業命理師，至少做到：

1. 列出八字四柱八個五行
2. 統計每個五行的數量
3. 找出**最少的 1-2 個五行**作為候選喜用神
4. 用調候法做交叉驗證（特別是冬夏出生）
5. 在輸出時明確告知：「這是粗略推算，建議由命理師確認」

## 不要做的事

- 不要把「缺什麼補什麼」當絕對真理（強旺命局再補同類就壞了）
- 不要因為地支藏干就武斷判定（這需要十年經驗）
- 不要對同一個八字宣稱「正確答案只有一個」 — 連大師都會吵
