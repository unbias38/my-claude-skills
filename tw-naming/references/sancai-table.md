# 三才吉凶對照表

三才 = (天格五行, 人格五行, 地格五行) 的組合，共 5×5×5 = **125 種**。

## 資料位置

完整 125 組存於 [`scripts/sancai_table.py`](../scripts/sancai_table.py)，
`wuge.py` 直接 import 使用。

```python
from sancai_table import SANCAI, grade_of_sancai

grade_of_sancai("木", "火", "土")  # → "大吉" (相生)
grade_of_sancai("金", "木", "土")  # → "大凶" (雙剋)
grade_of_sancai("水", "水", "水")  # → "大凶" (極端)
```

## 五行對照（從筆劃尾數推得）

| 尾數 | 五行 |
|---|---|
| 1, 2 | 木 |
| 3, 4 | 火 |
| 5, 6 | 土 |
| 7, 8 | 金 |
| 9, 0 | 水 |

(尾數即 `n % 10`，例如 11 → 1 → 木；24 → 4 → 火)

## 吉凶分布

本表 125 組：
- **大吉**：42 (33.6%)
- **中吉**：13 (10.4%)
- **凶**：52 (41.6%)
- **大凶**：18 (14.4%)

吉的比例約 44%，所以隨機組合中還有不少可用。

## 主要判斷邏輯（背景）

雖然腳本直接查表，理解原則有助於除錯與微調：

1. **三才相生（順生）→ 大吉**
   - 例：木→火→土（天生人，人生地）= 木火土 大吉
   - 例：金→水→木 = 金水木 大吉

2. **三才同行 → 多為大吉，但極端例外**
   - 木木木、火火火、土土土：大吉（生機飽滿）
   - 金金金：中吉（過剛）
   - 水水水：大凶（陰寒過盛）

3. **人格被天/地兩端剋 → 大凶**
   - 例：金木金（金剋木兩邊夾擊）= 大凶
   - 例：火水火（水剋火兩邊夾擊）= 大凶

4. **人格剋天或剋地（以下犯上 / 苛責下屬）→ 凶**
   - 例：木土X（人格木剋天格土）多為凶或中吉
   - 例：水火X、土水X（人格剋天格的逆生）多凶

## 派別差異

某些組合各派分歧較大，本表選用台灣命名師慣用版：

| 三才 | 本表 | 異派可能 |
|---|---|---|
| 木土火 | 中吉 | 凶（人格剋天格） |
| 金金金 | 中吉 | 凶（過剛） |
| 火土火 | 大吉 | 中吉 |
| 金水水 | 中吉 | 凶 |

如需重大決策，建議手動查證一個常見來源（如熊崎原書或台灣命名師專書）並覆寫 `SANCAI` dict。

## 高頻黃金組合

實務中最常被命名師採用的「萬用大吉」組合：

| 三才 | 適用情境 |
|---|---|
| 木火土 | 順生最理想，姓的天格五行配合喜用木 |
| 火土金 | 順生，喜用土/金 |
| 土金水 | 順生，喜用金/水 |
| 金水木 | 順生，喜用水/木 |
| 水木火 | 順生，喜用木/火 |

這 5 組是「五行順生」鏈條，幾乎不出錯。
