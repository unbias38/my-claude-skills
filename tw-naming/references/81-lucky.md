# 八十一靈動數吉凶表

熊崎健翁系統的核心 — 每個五格（天/人/地/外/總）的筆劃總數對應一個吉凶判定。

## 資料位置

完整資料以 Python 字典形式存於 [`scripts/lucky_81.py`](../scripts/lucky_81.py)，
為 `wuge.py` 的吉凶查表來源。本檔案是人類可讀說明。

```python
from lucky_81 import LUCKY_81, grade_of, info_of

grade_of(11)   # → "大吉"
info_of(11)    # → ("大吉", "旱苗逢雨", "中興之象，挽回家運")
grade_of(82)   # → "大凶" (mod 80 reduction: 82→2)
```

## 數值範圍處理

- 範圍 1-81。
- 超過 81 用 `((n - 1) % 80) + 1` 還原（即 82→2、161→1、80→80）。
- 各派對 `n > 81` 的處理略有差異，本表採 mod 80 主流寫法。

## 吉凶分級

本表用 6 級分類：

| 等級 | rank | 意義 |
|---|---|---|
| 大吉 | 5 | 全吉 |
| 中吉 | 4 | 良好 |
| 半吉 | 3 | 吉中帶凶 / 凶中帶吉 |
| 凶帶吉 | 2 | 凶為主，有轉機 |
| 凶 | 1 | 不吉 |
| 大凶 | 0 | 最凶 |

`大吉` + `中吉` 視為「吉」，`半吉` 以下視為需注意。
