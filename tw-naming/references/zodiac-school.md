# 生肖派姓名學

## 在這個 skill 中的角色：soft signal

生肖派**不參與三才五格的剪枝決策**，只在輸出時提供「加分/扣分」資訊讓使用者參考。

理由：
1. 生肖派在台灣命理界**爭議比三才五格大**——有派系視為附會（生肖只是十二地支之一，憑什麼字形要避開？）
2. 若當作硬篩選會讓候選空間崩塌——例如鼠年忌「人」「日」「火」字根，砍下去常用字幾乎全部被剔除
3. 三才五格本身已經是一個 partisan 的篩選器，再疊一個更爭議的硬篩，準確度與實用性都會下降

## 評分機制

每個名字字（不含姓）查 johnwu1114 的 12 個生肖對照表：

| 字在表中 | 分數 | 標記 |
|---|---|---|
| `better` 列表 | +1 | 宜 ✅ |
| `worse` 列表 | -1 | 忌 ❌ |
| 都不在 | 0 | 中性 ・ |

最後加總成「生肖總分」。`>=1` 視為偏吉、`<=-1` 視為偏忌、其他中性。

## 立春邊界問題

生肖以**立春**為界（約每年 2/4），不是西元 1/1。

例：2026/01/15 出生者，技術上仍屬 2025 年生肖（蛇），不是 2026 的馬。

腳本以 `年份 % 12` 推算，**1/1 至 2/4 之間出生者請改用 `--zodiac` 手動指定**：

```bash
# 2026/01/15 生 → 屬蛇
python scripts/zodiac_score.py 林某某 --zodiac 蛇
```

## 派別衝突的處理

`zodiac_score.py`（字級對照, 來源 johnwu1114）與 `zodiac_explain.py`（字根層級, 來源 wiki）來自不同 school，偶爾會出現：

> ✅ 莉 宜 (+1)  ← johnwu 的字級表判定
>   但 zodiac_explain 表中「莉」含「艹」對某些生肖是忌

這是**派別差異的真實反映，不是 bug**。命名師遇到時會手動權衡。建議：
- **總分一致時**（如全部都 +1 或全部都 -1）：可信度高
- **不一致時**：標示給使用者，不要自動裁決

## 何時該重視生肖派輸出

- 三才五格**全吉**但生肖**極忌**（如總分 -3 以下）→ 值得提醒使用者
- 三才五格**普通**但生肖**極吉**（如總分 +3 以上）→ 可作為差異化候選
- 大多數情況（生肖總分在 -1 到 +1 之間）→ **可以忽略**

## 何時該忽略生肖派

- 使用者明確說「不信生肖派」
- 候選名字寥寥無幾，不該再加篩選壓力
- 同名父母 / 祖輩在使用同類字根但活得很好（家族經驗權重 > 派別共識）

## 工程使用範例

```python
from zodiac_score import zodiac_from_year, load_zodiac_data, score_name

zodiac = zodiac_from_year(2026)  # → "馬"
data = load_zodiac_data(zodiac)
result = score_name(["志", "玲"], data)
# {'chars': [{'char':'志','score':1,...}, ...], 'total_score': 2}
```
