# 互動課程講義 / course-handout

一個 Claude Code skill —— 把任何「分部驟跟著做」的實作課程，做成**學員可以自己照著操作到底**的互動講義網頁（單檔 HTML，發布為 Claude Artifact）。講師投影著講，學員一邊點、一邊做、一邊打勾，做完領一張結業證書。

範本來自實際開過的課《君子動口不動手・排座位篇》——帶老師用六句提示詞在 Google 試算表裡蓋出排座位 App。

## 為什麼需要它

「跟著做」的課最怕兩件事：學員跟丟了不知道自己卡在哪一步，還有講義是給講師看的、學員拿到不會用。這個 skill 把每一部固定成「輸入這句 → 操作 → 驗收打勾 → 技巧」的節奏，連**預期會跳出的錯誤都寫成打勾項**（「跳出這個錯誤是正常的！下一部就來解決」），錯誤變路標，不是路障。

## 它做什麼

收集課程內容（課名、單元拆解、每部的提示詞／操作／驗收／技巧）之後，以 `assets/template.html` 為基底替換內容，產出一份帶著這些機制的講義頁：

| 機制 | 說明 |
|------|------|
| 單元收合 | 預設全部收起，點標題展開；單元底部「▲ 收起本單元」 |
| 提示詞一鍵複製 | 每段提示詞右上角複製鈕，三層備援（沙箱環境也能用） |
| 可打勾驗收清單 | 真核取方塊，勾完轉灰 |
| 術語浮動說明 | 反覆出現的動作（如「更新循環」）滑過去浮出步驟 |
| 畫筆標註 | 五色筆、橡皮擦、清除；筆跡跟著文字捲動；ESC 清空 |
| 🎓 結業證書 | 填姓名 → 檢查所有驗收 → 漏勾提醒哪一部；全過頒金框證書，2,500 種隨機頭銜，可下載 PNG |
| 📄 下載講義 | 整份講義打包成 Markdown 帶走 |
| 🎯 成果搶先看 | 頁首一鍵開啟完成品（例如試算表的 /copy 連結） |
| 深淺色主題 | 跟隨系統，投影字級（內文 22px） |

## 四種起點都能做

| 你有什麼 | skill 會怎麼做 |
|---------|------|
| 完成的專案＋提示詞 | 直接產講義 |
| 只有課程主題 | 先陪你把成品做一遍（過程就是提示詞和踩坑點的來源），再產講義 |
| 只有程式碼 | 逆向反推提示詞（用需求語言，不是技術規格），**試跑驗證**後再產 |
| 非 AI 課程（Excel、Canva…） | 泡泡裡放指令或步驟，機制完全通用 |

## 怎麼觸發

```
用 course-handout 幫我做「打掃分配表篇」的課程講義
我想開一堂 ○○ 的實作課，幫我做學員跟著做的講義網頁
把這個專案變成一堂課的講義
```

只要提到把課程、教學流程、工作坊、實作步驟「做成講義／網頁／教材頁」就會觸發，不一定要說「講義」兩個字。

### 跟其他講義類 skill 的分工

| 你想要的 | 用哪個 |
|----------|--------|
| 學員**跟著做**的分部驟實作課：提示詞複製、打勾驗收、證書 | **course-handout**（本 skill） |
| Google Codelabs 風格的閱讀型講義（時間標記、sticky 目錄） | `codelab-handout` |
| 忠實把 docx / pptx 轉成網頁 | `teaching-handbook` |

## 寫作原則（skill 內建）

- **講義是給學員看的**：講師看著能講、學員自己也能做到底；不寫講師心裡話、不重複介紹講師示範過的功能
- 一部＝一個能親眼驗收的成就；部數由課程決定（建議 4–8），不硬湊
- 驗收項必須可實測，含預期錯誤與暖身幽默項
- 提示詞裡立兩條通用規則：每次修改都給完整檔案；我只在成品介面操作、不回程式碼改參數

## 安裝

```
~/.claude/skills/course-handout/            # 全域可用
```

不需要額外安裝東西。產出主要走 Claude Code 的 Artifact 發布（頁面預設私人，從分享選單開給學員）；範本檔沒有 `<!doctype>`／`<head>`（Artifact 發布時會自動包），若要離線使用請自行補上。

## 檔案

```
course-handout/
├── SKILL.md              ← 流程、機制規格表、設計規範、寫作原則
└── assets/
    └── template.html     ← 完整成功案例，產出時整份複製再逐區塊替換內容
```
