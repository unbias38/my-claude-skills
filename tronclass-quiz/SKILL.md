# TronClass 小考出題

老師要的是一份學生「考前只看講義就能準備」的考卷，匯入 TronClass 後直接能用。
以下規則都是老師逐條定下的，背後的理由寫在旁邊，碰到規則沒涵蓋的情況，照理由判斷。

**先判斷是哪一種考試**：
- 各章小考、多章合考（全選擇題）→ 照本檔的規則與流程，產生 xls。
- **期中考**（有填空、計算題組）→ 出題規則 1～4、6、8、10 照本檔，題目組成、匯入格式、交付方式
  讀 `references/midterm-word.md`。

## 出題規則

1. **講義題只用講義上現成的題目**：隨堂小測驗與牛刀小試。
   不要自己新出題，就算內容取自講義也不行。學生練過這些題目，考試考的就是這些。
   牛刀小試是計算題，可以改成單選：題目與數字照舊，干擾選項取常見的算錯結果
   （漏算一項、用錯複利方式、先除後減…），讓錯誤選項有診斷意義。
2. **課本題**取自課本章末習題，答案要能在講義內容頁直接查到；計算題要能照講義上同類例子的邏輯算出來。
   選題前先到講義裡找到對應的那一頁，在解釋欄寫出節次。查不到的題目不要選。
3. **題目要自足，看完題目就能作答**：不可寫「圖 1.2」「表 7-8」「公式 2.7」「定理 1.1」
   「例題 7.4」「依課本的說法」這類要翻書的字眼。改寫方式是把那個圖表、公式或例題的關鍵內容
   直接寫進題幹（例：「公式 2.7 分母…」→ 把公式和符號意義寫出來）。答案與選項不變。
   計算題、問公式某一項意義的題目，要把完整公式與符號意義寫出來：不能「沒背公式就不會」。
4. **不考歷史，考觀念**：沒聽過這個事件、只學過本科觀念的學生，看完題幹答不出來的題目要改寫。
   課程要學的是本科觀念，事件只是素材。
   常見樣子：只寫事件名稱（「1998 年 LTCM 事件的教訓是？」）、考年代或人名（「風險長最早由誰在哪一年提出？」）、
   考統計數字（「某表哪國最高？」）、考課本案例公司名稱（「對應某某公司政策中的哪一條？」）。
   - 課本題遇到這種就換一題。
   - 講義題的改法：題幹先交代事件本質與經過（含關鍵數字，數字要能在講義查到），再問觀念或教訓；
     只描述發生了什麼，不要把結論寫進題幹，否則等於送答案。選項與答案字母盡量不變；
     選項本身就是史實（年代、人名）時，整題換成考同一頁觀念的題目，答案字母維持原本的。
   - 題幹已寫出關鍵事實、問的是觀念（例：「長榮設風管部後每年省 5,000 萬保費，最可能的做法是？」）就不用改。
   - 逐題讀來判斷，關鍵字（年份、事件名）只能抓到一部分。
5. **比例與題數**：講義約 90%、課本約 10%，共 25 或 30 題。
   講義題不夠時照實際題數走，並在回報時告訴老師實際比例（例：CH1 只有 21 題 → 講義 21＋課本 4＝25 題）。
   **多章合考**（2026-10-27 老師定）：講義隨堂小測驗全收、不刪題，不受 25／30 題上限，課本題照約 10% 補
   （例：CH2＋CH3 講義 36＋課本／圖表 4＝40 題）。各章原有的 questions.json 先和最新講義核對，一致就直接合併沿用。
   配分一定要給整數、剛好 100；難易題數配不出來時，說明原因並提出最小調整（例：把一題應用題改標高一級）。
6. **附圖**：老師喜歡有圖表題。從課本計算題挑一兩題配圖（價格走勢、現金流量、損益），
   把關鍵數字只放在圖上，讓學生必須看圖。圖不能直接洩漏答案（例：損益圖不要畫出合計線）。
   圖上若有編的示意數字（例如中間幾週的價格），回報時要說明。純觀念題不要硬配圖：
   觀念題的圖往往就是答案本身。
7. **答案分布**（xls 小考）：A～D 平均，同一字母最多連續 2 題（腳本自動處理）。
   數字型選項由小到大、含「以上皆是」「選項(A)(B)正確」的題目維持原順序（用 `fixed`）。
   期中考 Word 卷不重排，靠 TronClass 的選項隨機。
8. **每題填正確答案解釋**，寫算式或理由，並註明講義節次。
9. **難易度**照實標（易／中／難），然後給老師一組讓總分剛好 100 的配分（腳本會算）。
10. **不出有爭議的題目**（2026-10-13 老師定，起因：CH1 課本習題第 15 題「套利正確的敘述」，
   錯誤選項「需投入資金」實務上也說得通，29 人答錯、最後送分）。出題前每個錯誤選項都要問一次：
   「有沒有哪種合理解讀下它也是對的？」有的話就不能用。
   - 錯誤選項必須明確錯，不能是「實務上也成立」「看情況」「講義沒否定」的敘述。
   - 不出「選項(A)(B)正確」「以上皆是」這類組合選項：其中一個子選項有爭議，整題就跟著有爭議。
   - 課本題遇到這種就換一題；講義隨堂小測驗有這種題目，回報給老師，不要自己改。

## 流程（各章小考 xls）

1. **找最新版講義**：同一章可能有多個版本（`…CH02v5.pptx`、老師手改的 `…圖.pptx`），用最新的那份。
2. **抽講義題**：
   ```
   python <skill>/scripts/extract_handout.py <講義.pptx> <scratch>/chN_handout.json
   ```
   會列出隨堂小測驗、牛刀小試（題目、解答、答案、節次），並標出題幹裡依賴編號的措辭，這些要改寫。
   若講義的格式不同（沒有 `Ans{k}Letter` 形狀或「牛刀小試」標籤），改用 python-pptx 自己讀，
   或改從已整理好的習題 Excel（例如 `期貨市場習題.xlsx`）取題。
   題幹跨好幾段（一題拆成兩三行）時，extract_handout.py 會漏題；抽完核對題號是否連續，
   漏題就用 python-pptx 自己讀（題號段落之後、(A) 之前的段落都併進題幹）。
   抽完逐題檢查規則 4（不考歷史）。要改寫的題目先列「原題幹 → 新題幹」對照給老師看，
   並問一句講義要不要同步改（老師同意才改講義，另存新版、不覆蓋原檔；改完匯出投影片 PNG
   確認沒有超出版面、右側答案框與題幹對齊）。
3. **讀講義內容頁**（全部投影片文字），用來：驗證講義題的答案、挑課本題、寫解釋欄。
   也順便檢查講義本身的錯誤（例：牛刀小試的提示給錯數字），在小考裡修正並回報老師，講義本身不要動。
4. **挑課本題**：讀課本習題（PDF 或已整理的 Excel），挑答案在講義查得到的題目，其中一題計算題配圖。
5. **寫題目 JSON**（格式見 `scripts/build_quiz.py` 開頭的說明），照講義節次排序，課本題插在對應節次。
   每題欄位：`src`（講義N／講義牛刀N／課本N）、`diff`、`stem`、`answer`、`wrong`（3 個）、`fixed`、`expl`。
6. **畫圖**：matplotlib，字型用 `C:\Windows\Fonts\msjh.ttc`（Microsoft JhengHei），
   `axes.unicode_minus=False`，dpi 150，存到輸出資料夾，檔名用英數（例 `ch2_cashflow.png`），
   題幹裡寫 `@@ch2_cashflow.png@@`。畫完用 Read 看一次 PNG。
7. **產生 xls**：
   ```
   python <skill>/scripts/build_quiz.py <questions.json> <輸出資料夾>/<課程>_CHn小考.xls
   ```
   腳本會檢查選項、圖檔、依賴編號措辭，有問題就停下並列出；通過後印出答案序列、比例、難易度與配分建議。
   期貨課的慣例：輸出到 `小考\CHn小考\`，xls 與圖片放同一資料夾（TronClass 匯入時要求）。
8. **保留可重現的產製方式**：把 questions.json 放在輸出資料夾或專案的工具腳本資料夾，日後改題只要改 JSON 重跑。
   專案若有修改紀錄檔（例如 `提問修正.txt`），把這一輪附上。

## 回報給老師

用中文簡短說明：
- 檔案位置（xls＋圖，提醒放同一資料夾匯入；期中考是 docx）
- 題目組成：講義幾題（小測驗、牛刀各幾題）、課本哪幾題、實際比例
- 改寫過措辭的題目（原本依賴什麼編號、或原本只考歷史事件）
- 圖表題在第幾題、圖上有沒有示意數字
- 發現的講義錯誤（待老師確認）
- 答案分布、難易度題數、配分建議
- 牛刀改成單選是你做的轉換，若老師沒確認過，問一句要不要保留
- **最後問一句：要不要產生「原題對照」Excel**（老師定；每一題講義／課本原題 ↔ 考卷第幾題、題型、配分、
  是否改寫）。老師說要才產生，這份是給老師對題用的，不是每次都需要。
