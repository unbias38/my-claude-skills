# 學習筆記系統 / Learn Notes

一個 Claude Code skill —— 在專案裡建立「LEARN.md 目錄 + learns/ 逐篇筆記」的學習筆記系統，專為**不會寫程式的使用者**設計。每次跟 Claude 做完一件事，說一聲「做筆記」，就把這次學到的東西用白話 + 比喻寫成一篇日後看得懂的筆記。

## 為什麼需要它

跟 Claude 一起做完一個東西，過程中學到的觀念、踩過的坑，關掉視窗就忘了。這個 skill 讓每次收工都留下一份紀錄，而且是**用人話寫的**——半年後回來看還是看得懂。

## 它做什麼

在你的專案裡維護一個兩層式筆記系統：

```
你的專案資料夾/
├── LEARN.md               ← 目錄頁：一張表列出所有筆記（日期/主題/連結/一句話摘要）
└── learns/
    ├── 20260817_連結GitHub.md   ← 逐篇詳細筆記，一個主題一個檔
    └── 20260820_部署Vercel.md
```

每篇筆記固定包含：

1. **我們做了什麼？** —— 白話講這次完成的事
2. **為什麼這樣做？** —— 關鍵決定背後的理由
3. **學到的小知識** —— 可以帶走的重點
4. **遇到的問題與解決方式** —— 連「為什麼會發生」一起講，下次才認得出來
5. **未來小提醒** —— 要注意的坑

### 寫作風格（這個 skill 的靈魂）

- 全程白話，像朋友喝咖啡聊天，不是教授上課
- 大量比喻（「API 就像餐廳菜單，你點菜、廚房做好送出來」）
- 段落短、多用表格和條列，不出現嚇人的文字牆
- 自動加 Obsidian `[[雙括號連結]]`——把 `learns/` 丟進 [Obsidian](https://obsidian.md/) 就能看到知識關聯圖

## 怎麼觸發

**記錄**——做完事情後說：

```
做筆記
幫我筆記一下
更新 LEARN
記錄一下今天學了什麼
```

**複習**——想回顧時說：

```
複習
幫我查 LEARN
我學過什麼？
```

Claude 會讀目錄、列出你學過的主題，問你想深入哪一篇。

第一次使用不用任何設定：`LEARN.md` 和 `learns/` 不存在時，Claude 會自動建好並跟你說明怎麼用。

## 安裝

把資料夾複製到 Claude Code 的 skills 目錄即可，零依賴、不用裝任何東西：

```
~/.claude/skills/learn-notes/            # 全域可用
# 或
<專案>/.claude/skills/learn-notes/       # 只在該專案啟用
```

裝完重啟 Claude Code。詳細安裝指令（含 Windows）見 [repo 根目錄 README](../README.md#安裝)。

## 檔案結構

```
learn-notes/
├── SKILL.md     ← Claude 讀的工作流定義（觸發條件 + 筆記格式規則）
└── README.md    ← 你正在讀這份
```

筆記本身存在**你的專案裡**（`LEARN.md` + `learns/`），不會寫進 skill 資料夾。

## 設計原則

- **筆記屬於專案，不屬於 Claude**：所有筆記都是專案裡的普通 Markdown 檔，你可以用任何編輯器看、丟進 Obsidian、或跟著專案一起進 git 版控。明確禁止 Claude 把「做筆記」誤解成寫進它自己的內部記憶。
- **目錄只追加，不覆蓋**：`LEARN.md` 的表格只會加新列，舊紀錄不會被動到。
- **看得懂比完整重要**：寧可少寫，也不寫一篇半年後自己看不懂的技術文。
