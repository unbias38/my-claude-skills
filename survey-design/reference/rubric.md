# 問卷自評量表（Rubric）

> 綜合 COSMIN、Dillman、Boateng et al. (2018)、Stefana et al. (2025)、Morgado et al. (2017) 等框架，設計問卷完成後逐項自評。

## 使用方式

設計完問卷後，針對以下 8 個面向、共 24 個項目逐項評分。
- 每項 1-5 分
- 滿分 120 分
- 各面向有獨立小計，方便定位弱點

---

## A. 構念定義（15 分）

| # | 檢核項目 | 1 (不足) | 3 (尚可) | 5 (優良) | 得分 |
|---|---------|----------|----------|----------|------|
| A1 | 構念有明確的操作型定義 | 無定義或僅日常用語 | 有定義但邊界模糊 | 有文獻支持的精確定義，與相近概念明確區分 | /5 |
| A2 | 構念的子面向有系統性拆解 | 未拆解 | 有拆但依據不清 | 基於文獻或理論模型系統拆解 | /5 |
| A3 | 已檢視既有量表 | 未查 | 查了但未說明為何不採用 | 查了、比較了、說明了自編理由 | /5 |
| | **小計** | | | | /15 |

## B. 題目品質（25 分）

| # | 檢核項目 | 1 | 3 | 5 | 得分 |
|---|---------|---|---|---|------|
| B1 | 無雙重題意 | 有多題違反 | 有 1-2 題疑似 | 每題只問一件事 | /5 |
| B2 | 無引導性措辭 | 有明顯引導 | 有輕微暗示 | 措辭中立 | /5 |
| B3 | 語言清晰，無術語/雙重否定 | 多處難懂 | 偶有模糊 | 目標族群可直接理解 | /5 |
| B4 | 有明確時間框架 | 無時間框架 | 部分題有 | 所有需要的題目都有 | /5 |
| B5 | 無假設性前提 | 有未經篩選的假設 | 有 1-2 題疑似 | 所有假設都有對應篩選題 | /5 |
| | **小計** | | | | /25 |

## C. 回應格式（20 分）

| # | 檢核項目 | 1 | 3 | 5 | 得分 |
|---|---------|---|---|---|------|
| C1 | 選項互斥且窮盡 | 有重疊或遺漏 | 大致完整 | 完全互斥且窮盡 | /5 |
| C2 | 量尺點數適當（5-7 點） | 過少或過多 | 可接受但未最佳化 | 與構念特性匹配的點數 | /5 |
| C3 | 量尺標籤清楚 | 只有數字無文字 | 只標端點 | 每個錨點都有文字標籤 | /5 |
| C4 | 反向題使用合理 | 過多或配置混亂 | 有但未說明目的 | 適量使用且有明確的注意力檢核目的 | /5 |
| | **小計** | | | | /20 |

## D. 問卷結構（15 分）

| # | 檢核項目 | 1 | 3 | 5 | 得分 |
|---|---------|---|---|---|------|
| D1 | 題目順序合理（易→難，一般→敏感） | 順序混亂 | 大致合理 | 嚴謹遵循排序原則 | /5 |
| D2 | 分節清楚，有指導語 | 無分節或指導語 | 有分節但指導語不足 | 每節有清楚的標題與指導語 | /5 |
| D3 | 總題數適當 | 超過 50 題或少於能涵蓋構念的最低量 | 偏多或偏少 | 在完整性與填答負擔間取得平衡 | /5 |
| | **小計** | | | | /15 |

## E. 內容效度準備（15 分）

| # | 檢核項目 | 1 | 3 | 5 | 得分 |
|---|---------|---|---|---|------|
| E1 | 題目能涵蓋構念的所有面向 | 明顯遺漏 | 大致涵蓋 | 每個子面向都有對應題目，無遺漏 | /5 |
| E2 | 題目與構念的對應關係明確 | 無對應表 | 有但不清楚 | 有清楚的題目-面向對應表（blueprint） | /5 |
| E3 | 準備好可供專家評定的格式 | 無 | 有題目但無評定表 | 有完整的專家評定表（含 CVI 計算欄位） | /5 |
| | **小計** | | | | /15 |

## F. 偏誤控制（15 分）

| # | 檢核項目 | 1 | 3 | 5 | 得分 |
|---|---------|---|---|---|------|
| F1 | 降低社會期望偏誤的設計 | 無考慮 | 有意識但無具體措施 | 有匿名保證、間接題、或社會期望量表 | /5 |
| F2 | 降低默認偏誤（acquiescence bias） | 無考慮 | 有反向題但配置不佳 | 有適量反向題且分布合理 | /5 |
| F3 | 降低順序效應 | 無考慮 | 有考慮但未處理 | 有隨機化設計或經過順序效應檢驗 | /5 |
| | **小計** | | | | /15 |

## G. 可分析性（10 分）

| # | 檢核項目 | 1 | 3 | 5 | 得分 |
|---|---------|---|---|---|------|
| G1 | 每個因素至少 3-5 題 | 有因素只有 1-2 題 | 大部分符合 | 所有因素都有 3-5 題 | /5 |
| G2 | 計分方式明確 | 無計分說明 | 有但不完整 | 有完整的計分指引（加總/平均、反向題處理） | /5 |
| | **小計** | | | | /10 |

## H. 文件完整性（5 分）

| # | 檢核項目 | 1 | 3 | 5 | 得分 |
|---|---------|---|---|---|------|
| H1 | 有編碼簿（codebook）或題目對應表 | 無 | 有但不完整 | 有完整的變項名稱、編碼、對應面向 | /5 |
| | **小計** | | | | /5 |

## 等級判定

| 總分 | 等級 | 說明 |
|------|------|------|
| 100-120 | A | 可直接進入專家審查與預試 |
| 80-99 | B | 品質良好，需針對低分面向修正 |
| 60-79 | C | 需要大幅修改，建議回頭檢視構念定義 |
| < 60 | D | 建議重新設計 |

## 使用建議

1. 設計完問卷後立即自評
2. 低於 3 分的項目**必須修正**後才進入下一階段
3. 修正後重新評分，確認改善
4. 自評結果應附在問卷文件中，作為方法論透明度的一部分
