# 問卷設計常見缺陷清單

> 基於 Morgado et al. (2017)、Almanasreh et al. (2019)、Hinkin (1995, 1998)、Rattray & Jones (2007) 等文獻整理。

## 一、構念定義階段

| 缺陷 | 說明 | 後果 |
|------|------|------|
| 構念定義模糊 | 沒有明確的操作型定義，只有日常用語描述 | 題目設計失焦，效度無法建立 |
| 構念邊界不清 | 與相近概念（如焦慮 vs 壓力）未區分 | 區辨效度差 |
| 跳過文獻回顧 | 沒查既有量表就直接自編 | 重複造輪子，或遺漏關鍵面向 |
| 構念過度複雜 | 一份問卷試圖測量太多東西 | 填答負擔大，因素結構混亂 |

## 二、題目撰寫階段

| 缺陷 | 範例 | 修正 |
|------|------|------|
| 雙重題意 (double-barreled) | "這門課有趣又實用" | 拆成兩題 |
| 引導性措辭 (leading) | "你同不同意這個優秀的方案" | 移除評價詞 |
| 雙重否定 | "你不反對不實施..." | 改為正向句 |
| 語意模糊 | "你經常運動嗎？" | 加上頻率定義與時間框架 |
| 假設性前提 | "你對X的滿意度如何？"（未確認是否用過X） | 先加篩選題 |
| 社會期望題 | "你會歧視弱勢族群嗎？" | 用間接測量或情境題 |
| 專業術語 | "你的 self-efficacy 如何？" | 用白話文 |
| 絕對詞 | "你是否總是遵守規定" | 改為頻率量尺 |

## 三、回應格式階段

| 缺陷 | 說明 |
|------|------|
| 選項不互斥 | "1-5次" 和 "5-10次" 重疊 |
| 選項不窮盡 | 缺少"不適用"或"其他" |
| 量尺點數不當 | 2點太粗，11點太細；一般建議 5-7 點 |
| 缺少中間選項 | 強迫選邊可能造成無效回答 |
| 只標端點不標中間 | 填答者對中間點的理解不一致 |
| 正反向題混用不當 | 反向題太多造成困惑，且常被不認真的填答者忽略 |

## 四、問卷結構階段

| 缺陷 | 說明 |
|------|------|
| 題目過多 | 超過 50 題容易造成疲勞效應（fatigue effect） |
| 敏感題放開頭 | 填答者尚未建立信任就被問敏感問題 |
| 題目順序造成框架效應 | 前面的題暗示了後面題的"正確"答案 |
| 缺少指導語 | 填答者不知道該怎麼回答 |
| 跳題邏輯不清 | 條件題的指示模糊或矛盾 |
| 缺少進度指示 | 填答者不知道還要多久，中途放棄 |

## 五、效度準備階段

| 缺陷 | 說明 |
|------|------|
| 跳過專家審查 | 沒有外部檢驗內容效度 |
| 專家人數不足 | 少於 5 人，CVI 計算不穩定 |
| 沒做認知訪談 | 不知道填答者實際上如何理解題目 |
| 沒做預試 | 直接大規模施測，發現問題已來不及 |
| 樣本太小 | 因素分析需要足夠的樣本量（至少 5-10 倍於題數） |
| 樣本不具代表性 | 便利取樣偏離目標族群 |

## 六、報告階段

| 缺陷 | 說明 |
|------|------|
| 未報告刪題理由 | 讀者無法判斷刪題的合理性 |
| 未報告信度細節 | 只報 Cronbach's α 總值，不報各分量表 |
| 未報告效度證據 | 宣稱有效但沒呈現分析結果 |
| 未討論限制 | 迴避方法論上的不足 |
