1. **相關性（Relevance）**：這道題目與其所屬面向的相關程度

   - 2 = 需要大幅修改才相關

   - 3 = 大致可理解但可更清楚
   - 4 = 完全可理解

## CVI 計算區（研究者填寫）

### Item-level CVI (I-CVI)

計算方式：評定相關性為 3 或 4 的專家人數 / 專家總人數

| 題號 | 專家1 | 專家2 | … | 專家N | 同意人數 | I-CVI | 判定 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|------|
| {{ID}} | | | | | /N | | 見下方門檻 |

> 專家欄位請依實際人數增減。門檻依 Polit & Beck (2006)：**專家 N ≤ 5 時，I-CVI 須 = 1.00 才通過；N ≥ 6 時，I-CVI ≥ 0.78 通過**。

### Modified Kappa

| 題號 | I-CVI | pc | K* | 判定 |
|------|:---:|:---:|:---:|------|
| {{ID}} | | | | ≥0.74 通過 |

> pc = [N! / (A!(N-A)!)] × 0.5^N，其中 N = 專家人數，A = 同意人數
> K* = (I-CVI - pc) / (1 - pc)
