# 別名清單與台股黑話辨識

腳本第二個參數（別名清單）會大幅影響 PTT 搜尋命中率。多傳幾個別名，避免「PTT 冷清（其實只是搜不到）」的誤判。**Claude 應該根據常識先想好 2-4 個別名再傳**。

## 3. 🗣 台股圈黑話與口語簡稱辨識

使用者問股票時常用 PTT/論壇上的口語簡稱，**不能直接回「不知道你問哪一檔」** —— 要先反問釐清，並主動列出可能對應的個股給使用者選。

| 使用者口語 | 通常指的是 | 反問範例 |
|---|---|---|
| **「航海王」** | **航運三雄**：2603 長榮、2609 陽明、2615 萬海 | 「航海王是要看哪一隻？2603 長榮、2609 陽明、還是 2615 萬海？」 |
| **「護國神山」** | 2330 台積電 | 直接識別為 2330，不用反問 |
| **「金融股」**「金控」 | 富邦金 2881、國泰金 2882、中信金 2891、玉山金 2884 等 | 「金融股範圍很廣，你想看哪一檔？」 |
| **「蘋概股」** | 蘋果供應鏈：2317 鴻海、2354 鴻準、2474 可成 等 | 「蘋概股有好幾檔，你想看哪一檔？」 |
| **「電池雙雄」** | 1532 勤美、6121 新普、3211 順達 等 | 「電池雙雄通常指 X 跟 Y，你想看哪一隻？」 |
| **「半導體 / IC 設計」** | 2330、3034 聯詠、3037 欣興、3661 世芯 等 | 「半導體很多檔，你想看哪一檔？」 |
| **「AI 概念」** | 2330、3661 世芯、3017 奇鋐、3035 智原、6515 穎崴 等 | 「AI 概念股有好幾檔，你想看哪一檔？」 |
| **「貨櫃三雄」** | 2603、2609、2615（同航海王） | 同航海王 |
| **「散裝航運」** | 2606 裕民、2607 榮運、2615 萬海等貨櫃以外的 | 區分清楚再選 |
| **「銅板股」** | 股價低於 50 元的股票（範圍很廣） | 「銅板股很多，要看哪一檔？」 |
| **「妖股」** | 短線異常飆漲股（隨時間變化） | 「最近的妖股不太一樣，你心裡想的是哪一檔？」 |

**原則**：當使用者用範圍性口語（航海王、金融股、AI 概念）時，**禮貌反問選哪一檔**，不要自己亂猜。當使用者用單一指向性口語（護國神山、正二）時，可以直接識別不用問。

## 4. ⚠️ 槓桿/反向 ETF 的特殊辨識

當使用者說「**正二**」「**正 2**」「**反一**」「**反 1**」時，這些是**槓桿型 ETF 的口語簡稱**，**不要當成一般 ETF**處理。

| 使用者口語 | 真實代號 | 解釋 |
|---|---|---|
| 「0050 正二」「正二」 | **00631L** | 元大台灣 50 正向 2 倍（不是 0050） |
| 「正一」「0050」 | 0050 | 一般台灣 50 |
| 「反一」 | **00632R** | 元大台灣 50 反向 1 倍 |
| 「上證正二」 | **00633L** | 富邦上証正 2 |
| 「日本正二」 | **00640L** | 富邦日本正 2 |
| 「那斯達克正 2」「QQQ 正 2」 | **00670L** | FH 那斯達克正 2 |

**關鍵提醒**：
- 「正二」≠「0050」—— 這兩個 ETF 行為完全不同：00631L 是 0050 漲跌的 2 倍放大，波動劇烈
- 槓桿型 ETF 在 PTT 標題很少寫代號，常用「正二」「正 2」這類口語簡稱
- 別名清單一定要包含「正二」+「正 2」兩種寫法（用阿拉伯數字 2 還是中文「二」都有人寫）
