# 技術指標 → 市場情緒推測對應（通則）

此檔提供「不分標的類型」的通用對應原則。任何股票都先用這份表格做第一輪推測，再用 `asset_traits.md` 做標的類型校正。

---

## 核心原則：四個維度

股票的「市場情緒」線索主要看四個維度，正好對應寵物溝通師裡的「音高/長度/強度/重複性」：

| 寵物溝通維度 | 股票溝通維度 | 工具/指標 |
|---|---|---|
| 音高（Pitch） | **趨勢方向（Trend）** | 5/20/60 日均線、價格在區間的位置 |
| 長度（Duration） | **動能持續性（Momentum）** | RSI、MACD、KD |
| 強度（Intensity） | **波動程度（Volatility）** | 布林通道、年化波動率 |
| 重複性（Repetition） | **量能變化（Volume）** | 成交量 vs 20 日均量、量價關係 |

四個維度交叉判讀，比單一指標可靠很多。

---

## 維度 1：趨勢方向

### 均線排列

| 排列 | 訊號 | 對應市場情緒 |
|------|------|------|
| **多頭排列**（5MA > 20MA > 60MA） | 短中長期都向上 | 樂觀、多頭氛圍、買盤主導 |
| **空頭排列**（5MA < 20MA < 60MA） | 短中長期都向下 | 悲觀、空頭氛圍、賣壓主導 |
| **均線糾結** | 三條線靠在一起 | 猶豫、觀望、方向不明 |
| **MA5/MA20 黃金交叉** | 短期動能轉強 | 短期樂觀情緒升溫 |
| **MA5/MA20 死亡交叉** | 短期動能轉弱 | 短期擔憂情緒升溫 |
| **MA20/MA60 死亡交叉** | 中期趨勢轉弱 | 中期信心動搖 |

### 區間位置

| 位置（在近 60 日高低區間的百分位） | 對應情緒 |
|------|------|
| **>= 90%**（接近高點） | 興奮、追高、歡愉 — 也可能是「過熱」 |
| **70%-90%** | 偏強、健康上漲 |
| **40%-60%** | 中性、區間整理 |
| **20%-40%** | 偏弱、修正中 |
| **< 20%**（接近低點） | 悲觀、絕望 — 也可能是「超賣反彈點」 |

---

## 維度 2：動能持續性

### RSI（14 日）

| 數值 | 訊號 | 對應市場情緒 |
|------|------|------|
| **> 80** | 極度超買 | 極度貪婪、亢奮、注意拉回 |
| **70-80** | 超買區 | 樂觀偏熱 |
| **50-70** | 多方主導 | 健康上攻 |
| **30-50** | 空方主導 | 沉悶、修正 |
| **20-30** | 超賣區 | 恐慌、悲觀 |
| **< 20** | 極度超賣 | 極度恐慌 — 注意反彈契機 |

### MACD

| 狀態 | 對應情緒 |
|------|------|
| **DIF 在 DEA 上方且擴大** | 多方氣勢擴張，樂觀 |
| **DIF 在 DEA 下方且擴大（負方向）** | 空方氣勢擴張，悲觀 |
| **黃金交叉**（DIF 由下穿上 DEA） | 動能反轉向上的初訊 |
| **死亡交叉**（DIF 由上穿下 DEA） | 動能反轉向下的警訊 |
| **DIF 與 DEA 黏在零軸附近** | 沒有明確情緒，盤整 |

### KD

| K, D 關係 | 對應情緒 |
|------|------|
| **K > 80 且 D > 80**（高檔） | 短期超買，注意鈍化或拉回 |
| **K < 20 且 D < 20**（低檔） | 短期超賣，注意反彈 |
| **K 由下穿上 D**（黃金交叉） | 短期動能轉強 |
| **K 由上穿下 D**（死亡交叉） | 短期動能轉弱 |

---

## 維度 3：波動程度

### 布林通道位置

| 位置 | 對應情緒 |
|------|------|
| **貼上軌**（價 ≈ 中軸 + 2σ） | 短期過熱、追高情緒、注意回測中軌 |
| **中軸附近** | 中性、整理 |
| **貼下軌**（價 ≈ 中軸 - 2σ） | 短期超賣、恐慌賣壓、注意反彈 |
| **通道擴張**（上下軌張開） | 波動加劇，情緒劇烈 |
| **通道收斂**（上下軌靠近） | 等待方向，醞釀下一波 |

### 年化波動率

| 數值（年化%） | 解讀 |
|------|------|
| **< 15%** | 溫和（多為大型權值股、債券型 ETF、防禦型） |
| **15%-30%** | 中等（多數成熟股票、市值型 ETF） |
| **30%-50%** | 偏高（成長股、AI 概念股、半導體） |
| **> 50%** | 劇烈（小型股、生技、迷因股、加密貨幣相關） |

注意：波動率本身不是好壞，要配合趨勢看 — 多頭中的高波動 = 噴出，空頭中的高波動 = 崩跌。

---

## 維度 4：量能變化

### 量價組合（最關鍵的判斷之一）

| 組合 | 健康度 | 對應情緒 |
|------|------|------|
| **量增價漲** | ✅ 健康 | 共識性多頭，買盤積極認同 |
| **量縮價漲** | ⚠️ 注意 | 漲勢動能不足，可能是慣性上漲、留意背離 |
| **量增價跌** | ⚠️ 注意 | 賣壓沉重，恐慌或主力出貨 |
| **量縮價跌** | 🟡 中性 | 賣壓減弱，恐慌可能尾聲，但仍弱勢 |

### 量比 20 日均量

| 比例 | 解讀 |
|------|------|
| **> 2.0×** | 爆量（重大消息、主力進出、消息面震撼） |
| **1.2× - 2.0×** | 量增（市場關注度上升） |
| **0.8× - 1.2×** | 正常 |
| **< 0.8×** | 量縮（市場冷淡、觀望、無明顯共識） |

## 組合判讀（更可靠）

單一指標容易誤判，**至少兩個維度交叉**才有較高信心。

### 高信心多頭組合

| 組合 | 推測情緒 |
|------|---------|
| 多頭排列 + RSI 50-70 + 量增價漲 + 站上所有均線 | 健康多頭、共識性買盤 |
| 黃金交叉 + 從超賣區回升 + 量縮轉量增 | 反彈初動、空翻多 |
| 貼布林上軌 + RSI > 80 + 連續爆量 | 噴出/亢奮/過熱（要小心） |

### 高信心空頭組合

| 組合 | 推測情緒 |
|------|---------|
| 空頭排列 + RSI 30-50 + 量增價跌 + 跌破所有均線 | 趨勢性下跌、賣壓主導 |
| 死亡交叉 + 跌破 60 日線 + 爆量長黑 | 中期支撐失守，恐慌出清 |
| 貼布林下軌 + RSI < 20 + 量縮 | 極度恐慌、可能在尋找底部 |

### 警訊組合（**必須在輸出中標註**）

| 組合 | 警訊類型 | 建議行動 |
|------|---------|---------|
| 爆量長黑（量 > 1.5× 均量、跌幅 > 3%） | 主力出貨疑慮 | 觀察是否跌破關鍵均線 |
| 跌破 60 日線且原本站上 | 中期支撐失守 | 檢視持倉成本與時間部位 |
| 量價背離（價創新高、量縮） | 漲勢無力 | 警戒性減碼或觀望 |
| MACD 死亡交叉於高檔 | 動能反轉訊號 | 留意短中期賣壓 |
| RSI > 80 後快速下彎 | 超買後回挫 | 短線停利點 |

## 信心度判定指引

| 信心度 | 條件 |
|--------|------|
| **High** | ≥ 3 個維度有明確訊號且互相印證；新聞/Trends 也呼應 |
| **Medium** | 2 個維度有訊號，或 3 個維度但訊號不夠強 |
| **Low** | 歷史資料不足 < 30 個交易日 / 維度間訊號互相衝突 / 該標的類型較冷門 / 當日量未完整時的盤中判讀 |

**衝突案例**：例如「均線多頭排列 + RSI > 80（過熱） + 量縮（無支撐）」這種組合就是矛盾的，應標 Low confidence 並列出兩種可能（持續慣性漲 vs 即將拉回）。

## 新聞 + Google Trends 補充判讀

技術面是「股票自己怎麼動」，新聞和 Trends 是「外界怎麼看他」。兩者一致時信心高，不一致時要小心。

### 新聞情緒類別

| 新聞關鍵字 | 對應情緒 |
|------|------|
| 法說、財報優於預期、訂單能見度、AI/HPC 受惠 | 利多 |
| 下修財測、營收衰退、訴訟、停牌、減資、警示 | 利空 |
| 主力出貨、外資賣超、融資斷頭 | 散戶情緒警訊 |
| 新產品發表、合作公告、分割上市 | 中性偏多（看市場解讀） |

### Google Trends 走勢

| 走勢 + 股價對照 | 解讀 |
|------|------|
| 熱度上升 + 股價上漲 | 散戶 FOMO 進場、共識性追逐 |
| 熱度上升 + 股價下跌 | 散戶討論套牢、群眾恐慌情緒 |
| 熱度平穩 + 股價漲 | 法人主導、悄悄漲 |
| 熱度飆升 + 量爆增 | 風險升高 — 散戶湧入訊號常見於高點 |
| 熱度低 + 股價低 | 冷門期、可能是價值區 — 但也可能是被遺忘的下跌 |

## 多維熱度組合判讀（V2 新增）

V2 從多個來源抓「熱度」資料：PTT 股板提及率、Yahoo 留言累計、新聞密度、量比、三大法人買賣超、（可選）Google Trends。
**單一來源容易誤判，多源交叉才有價值** —— 重點看「散戶 / 媒體 / 法人」的方向是否一致。

### 四個熱度維度對照

| 維度 | 來源 | 反映什麼 |
|---|---|---|
| 🧑‍🤝‍🧑 散戶熱度 | PTT 股板提及率、Yahoo 留言、Google Trends | 業餘投資人關注度 |
| 📰 媒體熱度 | yfinance.news 近 3 日 vs 平常 | 主流媒體覆蓋度 |
| 💰 市場熱度 | 量比 20MA、量價關係 | 真實成交活躍度 |
| 🏛 法人方向 | 外資/投信/自營買賣超（**台股限定**） | 專業投資人方向 |

### 高信心交叉判讀

| 散戶 | 媒體 | 市場 | 法人 | 推測情緒 / 警訊 |
|------|------|------|------|---------|
| 熱議 | 飆升 | 量增價漲 | 買超 | **共識性強多頭**（信心 High，但留意過熱） |
| 熱議 | 飆升 | 量增價漲 | **賣超** | ⚠️ **散戶在追、法人在出**（典型高點訊號）|
| 冷清 | 平穩 | 量縮 | **買超** | 💡 **法人悄悄佈局**（可能是價值區，散戶還沒發現） |
| 熱議 | 飆升 | 量增價跌 | 賣超 | ⚠️ **新聞驅動的恐慌賣壓**（可能有重大利空） |
| 冷清 | 冷清 | 量縮 | 中性 | **被遺忘的股票**（沒事件、沒關注） |

### 為什麼「散戶熱 + 法人賣」是警訊？

行為金融學上有個經典觀察：**散戶情緒的高點，通常是法人撤退的時點**。
這不是說散戶都錯，而是：
- 法人持倉量大，「先進先出」需要在散戶接力時陸續減碼
- 散戶 FOMO 情緒最高漲時 → 成交量爆增 → 法人可以順利出貨
- 等散戶意識到法人在賣，往往已經是相對高點

PTT 股板 + 三大法人買賣超這兩個資料點同時看，正好捕捉這個訊號。

### 為什麼「散戶冷 + 法人買」值得留意？

相反地：當大多數人不關心一支股票，但法人持續買進，可能意味：
- 該股票被市場低估（價值投資機會）
- 即將有事件催化（如新訂單、新產品、監管利多）
- 法人有比散戶更早的資訊管道

**但這不等於「一定會漲」**。冷門 + 法人買也可能是「法人套牢中、被迫補進來護盤」。要結合技術指標、新聞、產業面綜合判讀。

### 顯示策略

- **至少要 2 個維度有資料才顯示「交叉判讀」區塊** —— 只有 1 個維度沒法交叉
- **Google Trends 失敗時直接不顯示「Google 搜尋熱度」這一行**（不要寫「無資料」）
- 美股沒有三大法人資料 —— 那一行用 `—` 帶過

## 使用者問題快速對照

使用者問題若提到下列關鍵字，可優先檢查對應指標：

| 使用者問題關鍵字 | 優先檢查 |
|----------------|---------|
| 「為什麼一直跌」「最近怎麼了」 | 是否跌破均線？爆量長黑？新聞利空？ |
| 「他在生氣嗎」「是不是不開心」 | 空頭排列？RSI 低檔？量增價跌？ |
| 「會不會再噴」「能不能加碼」 | 多頭排列強度？RSI 是否過熱？布林位置？量價是否健康？ |
| 「我該不該停損」 | 是否跌破 60 日線？空頭排列？警訊組合？|
| 「他現在好不好」 | 全面健檢：四維度交叉、警訊清單 |
| 「他在等什麼」 | 通道收斂？均線糾結？量縮觀望？ |
| 「他是不是要回頭」（指反彈） | RSI < 30？貼下軌？KD 黃金交叉？ |
