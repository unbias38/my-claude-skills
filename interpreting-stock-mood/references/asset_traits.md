# 標的類型行為特徵參考

只讀取使用者輸入標的對應的段落。其他段落不要載入到 context。

未列出的類型：直接根據 `technical_emotion_mapping.md` + 該標的的常識性產業知識推理，並在輸出中標註信心度為 medium 或 low。

---

## 🏛 大型權值股（市值前 10 大、藍籌）

**台股代表**：2330 台積電、2317 鴻海、2454 聯發科、2308 台達電
**美股代表**：AAPL、MSFT、GOOGL、AMZN、JPM

### 性格特徵

| 屬性 | 描述 |
|------|------|
| 脾氣 | 平常溫和，跟著大盤呼吸，但動起來會帶動整個指數 |
| 波動率 | 中等（通常 15-30% 年化） |
| 主導力量 | 外資、ETF 被動買盤、退休基金 |
| 最常見情緒 | 「淡定」「跟著市場走」 |

### 重要提醒

- 權值股漲跌常常是**整體大盤情緒**的縮影，比較少有純個股事件
- 如果權值股出現「爆量長黑」，往往是大盤系統性下跌，不只是個股問題
- 法說會、財報季前後是個股情緒最濃的時候
- 股息穩定，「除權息前後」會有明顯的價量變化，這是中性事件不要當訊號
- 美股權值股要留意 **Fed 利率政策、地緣政治** 對情緒的衝擊

### 擬人化口吻範例

> 「他平常很穩重，今天是因為大盤拉回所以也跟著被打到，他自己沒什麼事。」
> 「他在等下個月的法說，最近有點安靜，但量很穩。」

## 🚀 中小型成長股 / 概念股

**台股代表**：AI 概念（2376 技嘉、3037 欣興、3017 奇鋐）、IC 設計（3661 世芯）
**美股代表**：NVDA、PLTR、SMCI、TSLA、ARKK 成份股

### 性格特徵

| 屬性 | 描述 |
|------|------|
| 脾氣 | 情緒化，大起大落，新聞敏感度極高 |
| 波動率 | 高（30-60% 年化，有時更高） |
| 主導力量 | 散戶 FOMO、主力炒作、新聞題材、社群熱度 |
| 最常見情緒 | 「亢奮」「恐慌」兩極切換 |

### 重要提醒

- 一則新聞就可以讓股價跳 10%，**新聞情緒比技術指標更先動**
- Google Trends 熱度與股價的相關性，在這類股票最強
- 「量爆增 + RSI > 80」幾乎一定要警戒，因為散戶 FOMO 進場通常是相對高點
- 跌起來也很快，**沒有耐性的人很難持有**
- 法人持股比例低、籌碼集中在散戶，所以情緒劇烈
- 「股價噴出後 RSI 死亡交叉」常常是短期高點

### 擬人化口吻範例

> 「他最近真的很瘋，搜尋熱度也跟著飆，這種狀態通常不會持久。」
> 「他在等下一個題材，現在量縮意思是大家在觀望要不要追。」

## 🚢 景氣循環 / 航運 / 原物料

**台股代表**：2603 長榮、2609 陽明、2615 萬海（航運）；1303 南亞、1326 台化（塑化）；中鋼、原物料股
**美股代表**：FCX（自由港）、CLF（克利夫蘭鋼鐵）、海運 ZIM、油氣 XOM

### 性格特徵

| 屬性 | 描述 |
|------|------|
| 脾氣 | 雙極，極端 — 暴漲時人神共憤，崩跌時連跌幾季 |
| 波動率 | 極高（50%+ 年化是常態，旺季更猛） |
| 主導力量 | 大宗物資價格、地緣政治、運價指數、產業循環 |
| 最常見情緒 | 「大喜」「大悲」 |

### 重要提醒

- 看技術指標時，**一定要配合產業景氣與運價指數（如 SCFI、BDI）**
- 高股息往往發生在景氣高點，**高殖利率本身可能是警訊**（即將開始衰退）
- 「持續性大跌時」即使均線空頭、RSI 超賣，也不一定要急著抄底，因為循環下行可能持續半年到一年
- 突然的單日爆量大漲，往往跟運價、油價、消息有關
- 這類標的「擬人化」效果特別強烈 — 因為它的情緒真的很激烈

### 擬人化口吻範例

> 「他現在情緒很高昂，但他這個性格本來就是大起大落的，要小心情緒過後的反差。」
> 「他最近一直跌，但他這種人會一跌跌好幾個月，不要急著去接他。」

## 💎 高股息 ETF / 防禦型

**代表**：0056 元大高股息、00878 國泰永續高股息、00929 復華台灣科技優息、0050 元大台灣 50（部分歸類）；美股 SCHD、VYM

### 性格特徵

| 屬性 | 描述 |
|------|------|
| 脾氣 | 穩重大叔、慢條斯理、情緒含蓄 |
| 波動率 | 低-中（10-20% 年化） |
| 主導力量 | 退休族、穩定收益需求、被動買盤 |
| 最常見情緒 | 「淡然」「穩穩的」 |

### 重要提醒

- 技術指標的訊號**敏感度比個股低很多**，不要過度解讀短期波動
- **除息前後**價格會除掉股息，這是中性事件，不是「跌」
- 每月分配制（如 00929）的價格走勢有月度循環
- 持有人預期是「領息」不是「賺價差」，所以快速大跌時情緒比個股更恐慌
- 利率環境的影響大 — 升息環境對高股息 ETF 通常不利

### 擬人化口吻範例

> 「他不太會講話，這幾天沒什麼起伏，跟平常一樣慢慢散步。」
> 「他剛除息所以價格看起來下來，但這不是真的跌，他健康得很。」

## 🕊 市值型 / 大盤 ETF

**代表**：0050 元大台灣 50、006208 富邦台 50、VOO、SPY、QQQ、VTI
**美股代表**：SPY（S&P 500）、QQQ（納斯達克）、VTI（全市場）、VOO

### 性格特徵

| 屬性 | 描述 |
|------|------|
| 脾氣 | 佛系、整體市場的縮影 |
| 波動率 | 中等（15-25% 年化） |
| 主導力量 | 整體市場走勢、經濟大環境、政策 |
| 最常見情緒 | 「市場在說什麼，他就在說什麼」 |

### 重要提醒

- 個別技術指標反映的是**整體市場**情緒，不是任何單一公司
- 「跌破均線」事件對 ETF 而言代表整體大盤動搖，影響廣泛
- 適合長期定投者，**短期波動分析的意義較低**
- 「殖利率」不是重點，重點是長期累積報酬
- QQQ 與 SPY 之間的差異（科技股權重）會反映兩個市場情緒

### 擬人化口吻範例

> 「他就是市場本人，市場開心他就開心，市場不爽他就不爽。」
> 「短線跟他講不上話，他只回答長期的問題。」

## 🤖 AI 概念股（2024-2026 年特殊主題）

**台股代表**：2330（核心）、3661 世芯、3035 智原、6515 穎崴、3017 奇鋐、6531 愛普
**美股代表**：NVDA、AVGO、SMCI、PLTR、AMD（部分）

### 性格特徵

| 屬性 | 描述 |
|------|------|
| 脾氣 | 極度亢奮、被市場「神化」中、有點「網紅」氣質 |
| 波動率 | 高（30-60% 年化） |
| 主導力量 | AI 題材熱度、輝達相關供應鏈消息、外資追捧 |
| 最常見情緒 | 「FOMO」「AI 信仰」與「夢醒崩跌」交替 |

### 重要提醒

- 這個主題在 2024-2026 年期間是市場焦點，**估值已經偏高**，技術指標即使沒警訊也要審慎
- Google Trends 熱度跟股價的同步性極強
- 一旦 AI 主題退潮（任何小利空都可能觸發），跌幅可能也很可觀
- 「2330 + AI 概念」性格不太一樣 — 2330 因為市值大，相對穩，但仍受 AI 題材影響
- 建議結合 **NVDA 走勢** 看（NVDA 是 AI 板塊領頭羊）

### 擬人化口吻範例

> 「他現在像剛中了大獎的明星，每天都很興奮，但他自己也知道這個熱度撐不久，所以他偶爾會特別緊張。」
> 「他在等下一個 AI 大消息，最近沒新聞他就有點靜不下來。」

## 🧬 生技 / 製藥

**台股代表**：3107 大塚、6446 藥華藥、4966 譜瑞、6446
**美股代表**：MRNA、PFE、JNJ、生技 ETF（XBI）

### 性格特徵

| 屬性 | 描述 |
|------|------|
| 脾氣 | 神秘、二元 — 臨床試驗成功就噴、失敗就跳水 |
| 波動率 | 極高（個股可達 50-100%） |
| 主導力量 | 臨床試驗結果、FDA 審批、合作協議、學會發表 |
| 最常見情緒 | 「等待結果中的焦慮」「結果出來後的狂喜或絕望」 |

### 重要提醒

- 技術指標的解釋力**遠低於個股**，因為核心驅動是消息事件
- 「等待新藥三期結果」期間的低波動 ≠ 沒事，反而是事件前的安靜
- 不熟悉的生技股，**信心度應該標 Low**，因為散戶投資人很難評估科學風險
- 大型製藥（如 PFE、JNJ）波動性接近權值股，性格不同於小型生技

### 擬人化口吻範例

> 「他在等一個結果，這幾週的安靜其實是緊張的安靜，不是真的沒事。」

## 🪙 加密貨幣相關 / 迷因股

**台股代表**：(較少純加密相關)、5876 上海商銀(歷史性題材)
**美股代表**：MSTR（持有大量 BTC）、COIN、MARA、RIOT；GME、AMC（迷因股）

### 性格特徵

| 屬性 | 描述 |
|------|------|
| 脾氣 | 完全情緒化、社群驅動、24 小時在說話 |
| 波動率 | 極高（80%+ 年化常態） |
| 主導力量 | BTC 走勢、社群（Reddit、X）討論度、迷因 |
| 最常見情緒 | 「狂熱」「絕望」「FOMO」「FUD」 |

### 重要提醒

- 技術指標的可靠度**最低**，社群熱度（Trends）的權重極大
- 短時間 ±20% 是常態，不要被嚇到也不要追高
- 適合「玩」不適合「投資」的特性
- 信心度幾乎都該標 Low - Medium

### 擬人化口吻範例

> 「他根本不是個股票，他是個社群運動。今天他的情緒完全跟著迷因走。」

## ⚡ 槓桿型 / 反向 ETF（正二 / 反一 等）

**台股代表**：00631L 元大台灣 50 正 2、00632R 元大台灣 50 反 1、00633L 富邦上証正 2、00640L 日本正 2、00670L 那斯達克正 2、00715L 印度正 2
**美股代表**：TQQQ（QQQ 三倍正向）、SQQQ（QQQ 三倍反向）、SOXL（半導體三倍正向）、UVXY（VIX 兩倍）

### 性格特徵

| 屬性 | 描述 |
|------|------|
| 脾氣 | 跟標的指數**同方向但 2-3 倍放大**（正二）或**反向**（反一）；獨立性弱、跟著標的走 |
| 波動率 | 極高（正二大致是標的的 2 倍，年化 30-60% 是常態） |
| 主導力量 | 標的指數走勢（核心）+ 期貨換倉成本（隱性損耗） |
| 最常見情緒 | 「亢奮」「絕望」 — 因為放大效應，情緒會被「乘以 2」 |

### 重要提醒（這類最容易誤解）

- **不適合長期持有**：槓桿/反向 ETF 有「複利衰減」（compounding decay）—— 在震盪行情中，即使標的回到原點，槓桿 ETF 也可能淨值縮水。**長期定期定額幾乎一定虧**。
- **「正二」不等於「2 倍 0050」**：以 00631L 為例，他追蹤的是「**台灣 50 指數每日漲跌的 2 倍**」，不是「0050 ETF 淨值的 2 倍」。長期下來會跟「2 倍 0050」差很多。
- **正向 + 反向不能對沖**：00631L + 00632R 不會互相抵銷，因為複利衰減會兩邊都吃掉。
- **內扣費用較高**：管理費 + 期貨換倉成本，通常比一般 ETF 高 0.5-1%/年。
- **適合場景**：**很短的單向行情**（幾天到幾週、看得很準的時候）。當你「看好但只有少量資金、想用槓桿」時用，但**設好停損**。
- **PTT 用語**：「正二」「正 2」「T50 正 2」「拉正二」「正二倉」都是口語，分析時別名要帶齊。

### 解讀技術指標時的特殊調整

- **RSI 80+ 不一定真超買**：因為波動本身就大，正二的 RSI 達 80 是「常態」，要拉高超買警戒線到 85-90
- **均線斜率比位置重要**：正二跑很快，看絕對價位意義小，看「每天漲跌幅」更實用
- **量能訊號要看「標的 ETF」**：例如分析 00631L 時，配合看 0050 的成交量，因為主力動向會反映在原始標的
- **三大法人動向更重要**：散戶玩槓桿賠錢比例極高，法人是否進場更值得看

### 擬人化口吻範例

> 「他是個放大版的 0050 —— 0050 開心他就跳起來，0050 不爽他就摔倒。今天 0050 動了 1%，他就動 2%。」
> 「他不適合長期同住，是用來『短期看準了賺一波』的人，住太久他會把你累垮。」

## 🌏 海外冷門 ETF / 個股

**代表**：地區型 ETF（VWO 新興市場、INDA 印度、EWZ 巴西）、單一國家 ETF、產業冷門 ETF

### 性格特徵

| 屬性 | 描述 |
|------|------|
| 脾氣 | 性格不一，看追蹤指數 |
| 流動性 | 通常較低，單日量小 |
| 主導力量 | 該國/該產業整體經濟、匯率、地緣政治 |

### 重要提醒

- **公開資料有限**，技術指標解讀的信心度應標 Low - Medium
- 量小代表「爆量」「量縮」的訊號可靠度低
- 匯率變動會放大或抵消價格走勢，**不要忽略**
- 老實標註「該標的歷史資料有限，以下推測信心較低」
